## Public Commands
- `/info` - Show information about the bot
- `/submit` - Submit a record

## Restricted Commands
- `/register` - Register a new player
- `/edit name` - Edit a player's name
- `/edit nationality` - Edit a player's nationality
- `/ban` - Ban a player
- `/unban` - Unban a player
